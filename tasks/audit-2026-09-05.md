# DiaBloS Modern -- Improvement Audit (2026-09-05, read-only)

Branch `feat/wire-routing-and-block-shapes`, env `diablos` (Python 3.11.13, ruff 0.16.1 locally). `ruff check .` passes; 3.9-syntax AST parse over `lib/ modern_ui/ blocks/` is clean; `_BLOCK_MODULES` matches `blocks/` exactly (95 = 95). Unit suite: 1688 passed, 1 skipped.

## Executive summary

1. **The "unsaved changes" flag is broken end to end**: saving clears `model.dirty` but the GUI reads `dsim.dirty`; starting a simulation silently clears it; `closeEvent` never prompts and deletes the autosave. Users can lose work with no warning. (S / high)
2. **Monte Carlo / sweep workers mutate the live `DSim` while the 60 FPS repaint timer reads it** and can even re-enter the interpreter loop on the GUI thread. (M / high)
3. **Batch simulation runs synchronously on the GUI thread** behind a `processEvents()` band-aid; long runs freeze the window with no cancel. (M / high)
4. **Two blocks can hang the app** (`ZeroOrderHold`/`FirstOrderHold` on `sampling_time <= 0`) and three **silently falsify results** (FFT buffer never reset between runs; `MathFunction` and `LookupTable` substitute zeros/identity on bad input). (S / high)
5. **The interpreter's per-step propagation is O(blocks x (blocks + lines))** because adjacency is rescanned for every block execution instead of precomputed once. (S / med-high)
6. **Canvas repaints the whole widget every tick even when idle**, allocates ~5 `QPainterPath`s + gradients + font metrics per block per frame, and draws the grid one `drawEllipse` per dot. (M / high)
7. **Qt is imported in 98 files under `lib/` and `blocks/`** (every `draw_icon`, `file_service.py`, analyzers), so the engine cannot run headless without a Qt install. (L / high)
8. **Packaging drift**: frozen builds report a hard-coded `1.0.0`; dev deps allow any ruff `>=0.6` while CI pins `0.15.18`; the release workflow does not wait for tests; ~35 `print()` calls are invisible (and memory-leaking) in the windowed build. (S / med)

## 1. Correctness / latent bugs

**Dirty flag desync: save never clears the flag the GUI reads; running a sim does**
`lib/services/file_service.py:186,394` set `model.dirty = False`; the GUI writes and reads `dsim.dirty` (`modern_ui/managers/status_bar_manager.py:223`, `property_controller.py:76,90,109`, `connection_manager.py:402-428`, `clipboard_manager.py:338`), which `DSim` re-copies from the model only on add/remove/clear (`lib/lib.py:111,295,301,309,417`). Worse, `lib/lib.py:598` sets `self.dirty = False` inside `execution_init`, so pressing Run marks unsaved edits as saved. Fix: make `DSim.dirty` a property over `model.dirty`; remove the reset at `lib.py:598`. **S / high**

**No unsaved-changes prompt on close, and the autosave is deleted anyway**
`modern_ui/main_window.py:701-709`: `closeEvent` calls `_cleanup_autosave()` then `event.accept()` unconditionally. Fix: prompt Save/Discard/Cancel when dirty; delete the autosave only after Save/Discard. **S / high**

**Experiment workers share the live `dsim` with the GUI repaint timer**
`modern_ui/controllers/experiment_controller.py:140,238` pass `window.dsim` to `MonteCarloWorker`/`ParameterSweepWorker`; `lib/analysis/monte_carlo.py:100-124` and `lib/lib.py:713-777` (`run_tuning_simulation`) rewrite `blocks_list`, `line_list`, `timeline`, `execution_initialized` from the worker thread. `main_window.py:153-155` keeps `update_timer -> safe_update` running: `paintEvent` (`modern_canvas.py:379,442-446`) iterates `dsim.blocks_list`, and `safe_update` (`main_window.py:883-895`) reads `execution_initialized` and calls `dsim.execution_loop()` if it looks true. Fix: run experiments on a re-loaded `DSim` copy, or pause `update_timer` and set a busy guard while a worker is alive. **M / high**

**Tuning debounce timer can write params during a worker run**
`modern_ui/controllers/tuning_controller.py:37-40,117,129`: 50 ms single-shot writes `block.params[...]` and re-simulates on the GUI thread; nothing deactivates it before `worker.start()`. Fix: `tuning_controller.deactivate()` in `run_monte_carlo`/`run_parameter_sweep`. **S / med**

**ZOH / FOH loop forever when `sampling_time <= 0`**
`blocks/zero_order_hold.py:88-89`: `while params["_next_sample_time_"] <= time + 1e-9: += sampling_time` with no positivity guard; `blocks/first_order_hold.py:118-120` guards `< 0` only, so `0` hangs at `:141-142`. `discrete_transfer_function.py:96`, `discrete_statespace.py:129`, `rate_transition.py:165` all guard correctly. Fix: `if Ts <= 0: pass-through` (or `{'E': True}`), plus a regression test. **S / high**

**FFT buffer is never re-armed between runs**
`blocks/fft.py:86-94` initializes `_fft_buffer_`/`_fft_time_` only `if "_fft_buffer_" not in params` and declares no `_init_start_`. `reset_memblocks` (`lib/engine/simulation_engine.py:798-817`) clears only `_prev`/`mem`/`output`, and `_resolve_block_params` (`:632-641`) reuses `exec_params` on a cache hit, so consecutive runs compute the spectrum over concatenated histories. Fix: add `init_flag_param()` and reset on `_init_start_`. **S / high**

**Silent zero / identity fallbacks in `MathFunction` and `LookupTable`**
`blocks/math_function.py:132-136` returns `np.zeros_like(u)` on any exception (only a `logger.warning`). `blocks/lookup_table.py:26-33` `_parse_array` swallows parse errors and substitutes the default table with no log. Fix: return `{'E': True, 'error': ...}`. **S / high**

**Integrator method labels do not match the math**
`blocks/integrator.py:11,194-214`: "RK45" is a 4-stage fixed-step RK4. `:190-191` "BWD_EULER" does `mem += dt * mem_list[-1]` (lagged explicit Euler). Fix: rename to `RK4` (keep alias for saved files); implement or rename BWD_EULER. **S / med**

**Replay-loop feedthrough classification reads raw `params`, compile reads resolved `exec_params`**
`lib/engine/simulation_engine.py:1299-1305` uses `dst_block.params.get(...)` while `system_compiler.py:283-297` deliberately uses `runtime_params(block)` because workspace-variable params are strings. Fix: use `runtime_params(dst_block)` and reuse `block_matrices`. **S / med**

**Replay fallback executes blocks with raw `params`, no `dtime`, and swallows errors at DEBUG**
`lib/engine/simulation_engine.py:1697-1705`. Fix: pass `runtime_params(block)` and `dtime`, log at `warning` once per block. **S / med**

**`TransferFunction` breaks on vector input**
`blocks/transfer_function.py:137,145,150` compute `_Dd_ * u` then `y.item()`; a vector `u` raises. `StateSpace` uses the base `_process_input` check (`statespace_base.py:129-211`), TF does not. **S / med**

**`_replay_compiled_signals` Scope history grows a Python list of arrays**
`lib/engine/simulation_engine.py:1738,1759`. Preallocate `(num_steps, vec_dim)`. **S / low-med**

**Subsystem transfer-function extraction is a no-op stub**
`lib/analysis/analyzers/base_analyzer.py:65`: `if block.block_fn == "Subsystem": # TODO ... pass`. Fix: flatten first or raise "unsupported". **M / med**

**`StateVariable` swallows a bad `initial_value` and resets to `[1.0, 1.0]`**
`blocks/optimization_primitives/state_variable.py:122-123`. Return an error dict. **S / med**

## 2. Architecture / code smells

**`SimulationEngine` (2100 lines) contains a 574-line method**
`lib/engine/simulation_engine.py:1260-1834` `_replay_compiled_signals`: 22-branch `if fn ==` ladder that duplicates kernel math and re-implements `Scope.execute()` inline (`:1720-1760`). Seams: extract replay + `run_compiled_simulation` into `lib/engine/compiled_runner.py`; move `propagate_sample_times :1015-1125` / `identify_memory_blocks :988` next to `graph_analysis.py`. **L / med**

**Two engine facades: `DSim` (`lib/lib.py`, 1652 lines) over `SimulationEngine`**
~40 pure delegations (`lib.py:1231-1272`) plus 20 property shims (`:127-272`); `main_buttons_init :275-289` still builds pygame-era `Button`s (`lib/ui/button.py`) that `main_window.py:150` calls. **M / low**

**Block-type classification uses two incompatible normalizers**
`lib/engine/system_compiler.py:534-583` uses `b.block_fn.title()` against hand-duplicated spelling tuples, while `_create_block_executor` and the replay use `canonical_fn` (`lib/engine/block_names.py`). `check_compilability :122-183` uses a third scheme. Fix: `canonical_fn` everywhere. **S / med**

**Unreachable compiled kernels for excluded blocks**
`Hysteresis`, `Noise`, `Impulse`, `StateVariable` have kernels (`lib/engine/compiler_kernels/nonlinear.py:148`, `sources.py`, `routing.py`) but are absent from `COMPILABLE_BLOCKS` (`system_compiler.py:46-115`), so they and the `has_stochastic` branch (`simulation_engine.py:1930-1945`) never execute. **S / low**

**Qt imported throughout the engine and blocks**
98 files under `lib/` and `blocks/` import PyQt5: every `draw_icon`, `lib/services/file_service.py:11-12` (QFileDialog), `lib/simulation/connection.py:9-10` (QPainterPath in the data model), `lib/analysis/analyzers/lqr.py:164` (QMessageBox), inverted dependency `lib/plotting/field_scope_mixin.py:537 -> modern_ui.widgets.animation_export_dialog`. Fix: `draw_icon` returns plain geometry; move dialogs/plotting UI under `modern_ui/`. **L / high**

**Managers mutate `dsim.blocks_list`/`line_list` directly, bypassing the model**
`modern_ui/managers/history_manager.py:170-171,224`, `clipboard_manager.py:254,322`, `selection_manager.py:60`, `connection_manager.py:503`. Root cause of the dirty-flag desync. **S / med**

**Duplicated block logic**
TF vs DiscreteTF (`transfer_function.py:129-150` vs `discrete_transfer_function.py:103-133`); SS vs DSS (`statespace.py:96-112` vs `discrete_statespace.py:137-162`); sample-time gating copy-pasted 9 times with two epsilons (1e-9 in `zero_order_hold.py:89`, `first_order_hold.py:141`, `rate_transition.py:231,275`; 1e-12 in `packet_loss.py:206`, `network_channel.py:191`, `random_source.py:178`); delay interpolation (`transport_delay.py:144-167` vs `variable_transport_delay.py:167-195`); five identical analysis-marker blocks; `goto.py` vs `from_block.py`. `blocks/input_helpers.py` used by 4 blocks while 25 hand-roll `np.atleast_1d(inputs.get(`. **M / med**

**Stale "avoid circular import" deferrals**
`lib/simulation/menu_block.py:53-54`, `lib/models/simulation_model.py:84`, `lib/services/diagram_service.py:45` defer `theme_manager` imports needlessly. 73 function-level imports in `modern_ui/`. `simulation_engine.py:1881` re-imports `WorkspaceManager`. **S / low**

## 3. Performance

**Interpreter propagation rescans every block and every line per executed block**
`lib/engine/simulation_engine.py:1126-1170` `propagate_outputs` iterates all `target_blocks` calling `is_child_of` (`graph_analysis.py:74-80`), after `get_outputs` (`:40-48`) scans all lines. The replay loop already shows the fix (`inputs_by_dst`, `:1319-1327`). **S / med-high**

**Interactive interpreted run is throttled to one step per frame**
`modern_ui/main_window.py:153-155,893-895` calls `dsim.execution_loop()` once per tick (FPS = 60); a 10 s run at dt = 1 ms takes ~167 s wall. Fix: step until a ~10 ms wall-clock budget is spent per tick. **S / med**

**Idle full-widget repaint at 60 FPS**
`main_window.py:901` `self.canvas.update()` every tick; zero `update(QRect)` calls in `modern_ui/`. Fix: skip when not running and `_animation_should_run()` (`modern_canvas.py:282`) is false. **M / high**

**Per-block per-frame allocation in the renderer**
`modern_ui/renderers/block_renderer.py:268,277,283,286,280,186-192,373,331,448`; `draw_icon` re-run and `QTransform.map`-ed every frame (`:291,319`); `QFontMetrics` at `:499,1060`, `connection_renderer.py:70,285`, `canvas_renderer.py:444`. Fix: cache paths on `DBlock` keyed by `(rect, flipped, shape)`. **M / med**

**Grid drawn dot by dot**
`modern_ui/renderers/canvas_renderer.py:156-166`: `drawEllipse` per grid point. Fix: `drawPoints(QPolygonF)` or tiled `QPixmap`. **S / med**

**`get_color` re-parses hex per call** (`lib/theming/theme_manager.py`); ~21 calls per block per frame. Memoize. **S / med**

**All wires re-laid-out on every drag move**
`modern_ui/managers/connection_manager.py:542-548`; `_reroute_affected_lines` (`modern_canvas.py:533-559`) already filters. **S / low-med**

**Small hot-path items**: f-string log per block per step (`simulation_engine.py:656`); `blocks/delay.py:108-109` `list.pop(0)` (use `deque`); `blocks/lookup_table.py:141,265-267` rebuilds interpolators every step. **S / low**
